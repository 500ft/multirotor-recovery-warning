Ranks aircraft design packages by exact 95% lower bound on survival probability; it is not a runtime policy (design.md 6b). Simulation-only prediction. Action inputs are estimates pending owner input (OQ-010). Baseline PD controller (variant a). Each row is one failure-state cell: release height [m], initial vertical speed [m/s], tumble rate at failure [rad/s] and detection delay [s], as the tick labels list them. Each column is one failure class. The marker names the best package (reallocation: circle, mechanism: square); filled means its interval is clear of the others, hollow means it lies within Monte Carlo uncertainty of another package. A cell without a marker has every lower bound at 0. The number is the best package's lower bound; a positive bound below 0.005 prints as <0.01. No design package is clearly best in any of the 96 failure-state cells. 30 trials per cell (300 in outlined primary cells); parachute-like device 2,000. Horizontal rules separate release heights. Values: Data/survivable_set_results.json (policy rows).
