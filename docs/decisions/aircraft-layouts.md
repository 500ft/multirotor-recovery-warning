# Aircraft layout selection

The owner selected Variant C as the fully equipped layout and the MicoAir H7 aircraft as the low-cost layout. RevS remains the reference aircraft to build first. RevAB stays frozen and is excluded from the new packages.

The [aircraft package](../../cad/aircraft_r1/README.md) contains generated component CAD, SOLIDWORKS 2026 assemblies, bills of materials, geometry checks and retained desktop simulation runs. Supplier specifications corrected the sensor envelope, landing clearance, battery model and ESC mass. The numerical records live with each aircraft.

This decision selects CAD configurations and authorizes their publication on the owner's portfolio. Hardware access, purchasing, powered-bench approval and contained flight approval retain their existing gates. The component and outcome qualification steps in the roadmap remain in force.
